# Remote Jobs Tracker

A small web app that collects live remote software jobs and shows them in a searchable dashboard.

**Live demo:** https://tazitahmed1-code.github.io/remote-jobs-tracker/

## How it works
1. A Python script fetches remote software jobs from a public API (Remotive).
2. The script generates a static HTML page with the jobs embedded.
3. The page is hosted on GitHub Pages and has instant client-side search.

## Tech stack
Python, requests, JavaScript, HTML/CSS, GitHub Pages
